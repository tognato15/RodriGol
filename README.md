# RodriGol 2.0

Sistema operacional para cobertura esportiva, produção editorial e apresentação em tempo real.

## Estado atual

Sprint 01 — Platform Foundation  
Entrega 01 — Foundation Skeleton + Identity System

## Requisitos

- Node.js 22 ou superior
- npm 10 ou superior

## Comandos

```bash
npm install
npm run check
npm test
npm run build
```

## Pacotes atuais

- `@rodrigol/core`: contratos e componentes fundamentais independentes de esporte, interface e infraestrutura.
