# Checklist de Rodada — RodriGol Studio RC1

## Antes da rodada
- [ ] Executar `npm run preflight`.
- [ ] Abrir Central e confirmar partidas do dia.
- [ ] Conferir clubes, escudos e competições.
- [ ] Conferir escalações e bancos.
- [ ] Conferir árbitro, público e clima quando disponíveis.
- [ ] Abrir Multicabine.
- [ ] Abrir Overlay Studio.
- [ ] Confirmar conexão do Bridge.
- [ ] Confirmar jogo principal.
- [ ] Confirmar ticker editorial e barra lateral.

## Ao iniciar cada partida
- [ ] Iniciar jogo com relógio ou modo sem relógio conforme necessário.
- [ ] Confirmar entrada automática no scoreboard.
- [ ] Confirmar status correto no card lateral.
- [ ] Confirmar relógio sincronizado entre Cabine, scoreboard e lateral.

## Durante a partida
- [ ] Registrar gol e conferir placar.
- [ ] Conferir autor/minuto no scoreboard.
- [ ] Conferir ação na tela branca.
- [ ] Conferir Sumário da Partida.
- [ ] Registrar cartões e conferir Sumário.
- [ ] Testar substituição: quem sai / quem entra.
- [ ] Confirmar que reserva utilizado deixa de aparecer como disponível.
- [ ] Confirmar que jogador que entrou passa a ser considerado em campo.
- [ ] Conferir classificação AO VIVO após mudança de placar.

## Intervalo
- [ ] Confirmar status INTERVALO em todos os componentes.
- [ ] Confirmar ocultação correta do relógio.
- [ ] Confirmar classificação ao vivo.

## Segundo tempo
- [ ] Confirmar reinício do relógio.
- [ ] Confirmar status 2º TEMPO.
- [ ] Fazer nova substituição e verificar listas.
- [ ] Se possível, substituir um jogador que entrou anteriormente.

## Fim de jogo
- [ ] Encerrar a partida na Cabine.
- [ ] Confirmar saída automática do scoreboard.
- [ ] Confirmar FINAL no card lateral quando aplicável.
- [ ] Confirmar classificação OFICIAL.
- [ ] Conferir Sumário final.
- [ ] Confirmar preservação dos dados no Histórico/Arquivo.

## Depois da rodada
- [ ] Anotar bugs encontrados.
- [ ] Classificar cada bug: bloqueador / alto / médio / baixo.
- [ ] Não alterar funções aprovadas sem necessidade.
