# @rodrigol/football — v0.2.0

Domínio completo de futebol do RodriGol 2.0.

## Capacidades

- partida, placar, períodos, cronômetro e timeline;
- gols, pênaltis, cartões, substituições, VAR e estados excepcionais;
- equipes, jogadores, comissão técnica, formação e escalação;
- disciplina individual e expulsão por segundo amarelo;
- estatísticas de partida e de jogadores;
- disputa de pênaltis cobrança por cobrança;
- competições, temporadas, fases, grupos, rodadas, classificação e desempates;
- confrontos eliminatórios com ida e volta;
- eventos de domínio para integração com os próximos motores.

## Validação

Na raiz do projeto:

```cmd
npm install
npm run check
npm test
npm run build
```
