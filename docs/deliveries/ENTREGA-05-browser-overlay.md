# Entrega 5 — Browser Overlay

## Concluído

- aplicação `apps/overlay` integrada aos npm workspaces;
- fundo transparente para OBS;
- tema escuro com identidade laranja do RodriGol;
- placar, relógio, ticker, lower third, alerta lateral, manchete e tela cheia;
- transições de entrada e saída;
- comandos compatíveis com o vocabulário do `@rodrigol/overlay`;
- comunicação local por API global, `postMessage`, evento customizado e BroadcastChannel;
- modo de demonstração `?demo=1`;
- servidor local sem dependências externas;
- validações automatizadas.

A Entrega 6 acrescentará a ponte WebSocket e a sincronização em tempo real com as demais aplicações.
